## 操作の試し方

- コマ編集：コマを選んで内部を移動、青8点を拡縮。外枠・他コマの水平垂直位置・既存間隔へスナップします。Altまたはスナップ設定OFFで解除。Ctrl+クリックで複数選択し、全体の移動/拡縮も試せます。
- 頂点・分割：1ページ目の多角形を1つ選び、内側点を移動、辺/頂点を右クリック。4点分割は四角/凸多角形に対して外周2点→帯幅→対側交点。結果は既存の斜め分割と比較できます。
- Undo/Redo・取消：移動や設定変更の後にCtrl+Z/Ctrl+Y。ドラッグ途中のEscは取消。Undo履歴は保存データではなく実行中の操作から作られます。
- 吹き出し：2ページ目を選び、本体輪郭や文字/色を変更して「文字・設定を反映」。しっぽツールで個別の根元・幅・先端を変更。3ページ目で文字配置ツールや「専用文字入力」を試します。縦入力の疑似カーソルは横線です。
- 効果：4ページ目で効果素材・フィルター・枠を切り替え、素材を個別に移動/拡縮/削除します。
- 共通プリセット：コマ割り管理に「サンプル・形状と斜め分割」「サンプル・6コマの効果比較」。設定メニューに900×1200/余白40のページ基準と「サンプル・図形の街」の画像生成指示。作品には指示のコピーも保存されています。
- 管理：キャラ管理で親/服装状態、画像管理で背景/子/別位置/タイトルと人物参照を確認できます。管理の変更はこのサンプル専用ライブラリだけに反映されます。
- 出力：PNG出力は1つの画面に未配置/参照切れ・画像重複の注意、出力対象、出力先を表示します。変更のみ/すべてを試せます。Project/Outputには確認済み6枚PNGがあり、未変更の差分出力は再描画0枚です。

## 保存と持ち運び

App・Data・Projectを含めて、このフォルダー全体を保持してください。画像/効果は相対参照で作品内、人物と共通プリセットはData内にあります。Start-Sampleは現在のフォルダーからDataを指定するので、通常のDocuments/MangaMakerを使いません。通常版EXEも同梱しました。このPCのWindows実行環境で確認しています。

図形と色だけの小さいBMP、アプリ組込の透明PNGを使っています。AI画像生成・AI通信は実行していません。生成プリセットと派生関係は保存済みですが、外部生成サービスの接続/通信を再現するサンプルではありません。

現行ソースのSaveProject/OpenProjectFileとPNG出力処理で正式保存・再読込、6枚出力と未変更0枚再描画を確認し、非表示の実VCLコントロールでページ/管理画面を撮影しました。Project/OutputとScreenshotsで見た目を確認できます。人の手による実IME候補操作、物理的なDPI切替、長時間制作、ルビ/高度組版は対象外です。キャラ仮画像は三面図を描き分けたものではありません。

## 表示の拡大縮小と移動

ホイールでマウス位置を基準に拡大縮小、中央ドラッグで表示移動、Ctrl+0で全体表示です。選択/文字配置/しっぽ編集では、何もない位置からの左ドラッグでも表示移動できます。対象本体やハンドルの編集とCtrl選択を優先し、作成/分割/しっぽ追加などの左クリックは従来どおり点入力に使います。表示操作では作品データやUndoは増えません。新版EXEとZIPを同期済みです。検証は各1728 PASS、ネイティブ111件と読込UI42件、CLI4件です。
